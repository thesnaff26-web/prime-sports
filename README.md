# PRIME Hockey Lab 1.0 — новое самостоятельное приложение

## Запуск с iPhone через GitHub
1. Создайте новый публичный репозиторий `prime-hockey`, ветка `main`.
2. Распакуйте ZIP. Загрузите **содержимое** папки `prime` в корень репозитория. Не сам ZIP. Обязательно загрузите `.github/workflows/prime.yml`: если приложение «Файлы» скрывает папку, создайте этот путь через GitHub → Add file → Create new file и вставьте текст из `WORKFLOW.txt`.
3. Settings → Pages → Source → **GitHub Actions**.
4. Actions → PRIME — update and publish → Run workflow → Run workflow. Первый запуск собирает историю и может занять несколько минут.
5. Ссылка появится в Settings → Pages и в результате запуска Actions. На iPhone: Safari → Поделиться → На экран «Домой».

Бот запускается примерно каждый час на стороне GitHub, даже когда приложение закрыто. Плановые запуски могут задерживаться; в публичных неактивных репозиториях GitHub может отключать расписание. Повторно включите его в Actions. Права Actions должны разрешать запись содержимого и публикацию Pages. Не заменяйте этим пакетом старый проект: это отдельное приложение.

## Что работает
- КХЛ и НХЛ: автоматическая загрузка расписания и завершённых игр.
- Раздельная проверка фиксированной модели Elo на истории текущего сезона.
- Победитель с ОТ и буллитами, строгий отбор, фиксация до матча.
- Автоматический расчёт выигранных/проигранных прогнозов, общий и раздельный счётчик.
- Интерфейс для телефона, фильтры лиг, история, диагностические статусы, офлайн просмотр последних данных после первого открытия.
- Не нужны Telegram, OpenAI или платные ключи.

## Точность
Гарантий нет. Расчётная оценка Elo не откалибрована. Порог 65% не означает реальную проходимость 65%. Фильтр открывает публикацию после минимум 60 исторических прогнозов и нижней 95% границы Wilson выше 50%. В начале сезона прогнозов может долго не быть. Историческая проверка не доказывает будущую прибыльность. Не учитываются коэффициенты, составы, вратари и травмы. Не применяются догон, увеличение ставок или автоматические ставки.

КХЛ использует существующий адаптер Webcaster из вашего проекта; формат и доступность внешнего сервиса могут измениться. При ошибке приложение показывает проблему и прекращает новые публикации для лиги. Числовые статусы и нераспознанные результаты не угадываются. НХЛ использует api-web.nhle.com. Предсезонные матчи НХЛ исключены. Данные прошлого сезона не смешиваются с текущим. Победы в буллитах учитываются по итоговому счёту источника.

Состояние хранится в `data/state.json`, публичный результат — `data/feed.json`. Не удаляйте state.json: в нём архив предварительно опубликованных прогнозов. Новые прогнозы не переписывают старые. Публичный репозиторий позволяет владельцу менять файлы — история не является криптографически защищённой. Отменённые/перенесённые игры не считаются проигрышами автоматически, остаются в ожидании результата. Личные данные не собираются.

## Проверка
`python -m unittest discover -s tests`
`python bot.py`

В среде сборки выполнены автономные тесты и синтаксические проверки. Доступность спортивных источников и успешный запуск GitHub Actions нужно подтвердить первым запуском в вашем репозитории. Заявленная будущая точность отсутствует.
