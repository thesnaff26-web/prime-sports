PRIME 2.1 — NHL + KHL

CHANGES:
- KHL schedule source connected to KHL mobile API (third-party documented endpoint).
- Clear KHL API errors in GitHub Actions instead of silent zero results.
- API fetched once per run and deduplicated.
- NHL model, 18h rule, hourly Actions and existing history retained.
- KHL forecast publication is intentionally OFF until historical model validation.
- No football.

INSTALL:
1. Upload files to repository root, preserving folders and hidden .github directory.
2. Keep your existing data/state.json and data/predictions.json. This ZIP excludes both.
3. Actions -> PRIME - Auto forecasts -> Run workflow.
4. Read 'KHL API:' and 'KHL YYYY-MM-DD:' log lines. If ERROR, share full text.

IMPORTANT: KHL mobile API response was not accessible from the build environment.
The adapter has been syntax-tested and tested against sample fixtures, not live KHL data.
A successful GitHub Action and nonzero KHL fixture count are needed to verify it.
No unvalidated KHL bets are published.
